## Ritm de lucru

- **Săptămânal:** fiecare trimite pe grup 3 rânduri: ce a făcut, ce face, unde s-a blocat.
- **Pull request-urile** primesc review în cel mult 2 zile.
- **Board-ul** din GitHub Projects arată cine ce face: _De făcut → În lucru → În review → Gata_.
